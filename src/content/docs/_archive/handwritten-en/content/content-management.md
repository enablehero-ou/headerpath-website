---
title: Content Management
description: Create, organize, and publish content pages in your Qurioos account.
---

Content in Qurioos is organized as **Pages** (content pages) containing **Steps** (content blocks). Users navigate through steps one at a time.

### Page settings

Each page has the following settings:

| Setting | Description |
|---------|-------------|
| **Title** | Displayed in the catalog and navigation |
| **Status** | Draft, Published, or Coming Soon |
| **Visibility** | Public, Logged in, or Groups |
| **Featured** | Highlights the page in the featured section |
| **Show in nav** | Whether the page appears in the user sidebar |
| **Certification** | Whether users earn a certificate on completion |

### Step types

| Step type | Use for |
|-----------|---------|
| **Section** | Chapter headings or intro screens |
| **Text** | Prose content and explanations |
| **Image + Text** | Alternating image and text blocks |
| **Video** | Embedded (YouTube, Vimeo) or Mux-hosted video |
| **Quiz** | Single multiple-choice question with feedback |
| **Recap** | Animated bullet-point summary |
| **Podcast** | Audio step with optional read-along transcript |
| **CTA** | Call to action with a button link or session link |
| **Form** | Feedback (emoji), reflection (text), or assignment (file upload) |

### Labels and callouts

Every step can include optional extras:
- **Labels** — a badge shown on the step: *Reflect, Think, Essential, New, Idea, Recap, Tip, Challenge, Aha, Goal, Fact*
- **Callouts** — a highlighted box in the step: *Motivation, Alert, Tip, Note, Quote*

### Draft and publish

Changes saved in the editor are stored as a **draft** until you publish. This lets you work on updates without affecting what users see. When ready, set the page status to **Published**.

### Form responses

Responses submitted by users to Form steps are available under the page's **Responses** tab in the admin panel.

**Need to know**

- Edit locks prevent two editors from overwriting each other's changes. If a page is locked, wait for the other editor to finish or unlock it manually.
- Content can be translated into additional languages. Enable locales first under **Settings → Localization**.
