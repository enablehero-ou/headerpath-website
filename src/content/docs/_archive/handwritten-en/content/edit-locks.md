---
title: Edit Locks
description: How Qurioos prevents two editors from overwriting each other's changes.
---

When two admins or editors open the same page in the content editor at the same time, **edit locks** prevent them from overwriting each other's changes.

### How edit locks work

When you open a page in the editor, Qurioos acquires a lock on that page for your session. If another user tries to open the same page while you have it locked, they see a notice that the page is currently being edited.

The lock is held for the duration of your editing session and is released when you navigate away or close the editor.

### What to do if a page is locked

If a page you need to edit is locked by another user:

- Wait for the other editor to finish and navigate away
- Contact the editor directly and ask them to save and close the page
- Use the **Unlock** option if the original editor is no longer active

### How to unlock a page

If the original editor is no longer working on the page (e.g., their session ended unexpectedly), an admin can manually unlock it:

1. Open the page from the content list
2. Click **Unlock** in the lock notice

After unlocking, you can open the editor normally.

**Need to know**

- Unlocking a page while another editor has it open may result in lost changes for that editor. Only unlock when you're confident the page is no longer actively being edited.
- Locks apply to the page level, not individual steps.
