---
title: Form Steps
description: Collect user feedback, reflections, and file submissions with Form steps.
---

**Form steps** let you collect structured input from users as part of a content page. They're useful for gathering feedback, prompting reflection, or collecting assignment submissions.

### Form types

| Type | What it collects |
|------|-----------------|
| **Feedback** | A quick emoji reaction (e.g., thumbs up/down, star rating) |
| **Reflection** | A written text response |
| **Assignment** | A file upload from the user |

### How to add a form step

1. Open a page in the editor
2. Click **Add step**
3. Select **Form**
4. Choose a form type and configure the options

### Configuring each type

**Feedback** — Customize the emoji labels shown to users. For example, change the default emojis to match a 1–5 scale or a sentiment spectrum.

**Reflection** — Set a placeholder prompt to guide the user's response (e.g., "What will you do differently after this module?").

**Assignment** — Configure the allowed file types (e.g., PDF, images), maximum file size, and maximum number of files per submission.

### Viewing responses

Responses to form steps are stored and viewable under the page's **Responses** tab in the admin panel. Each response is tied to the user who submitted it.

**Need to know**

- Users must be logged in to submit a form step. Anonymous users on full-public academies cannot submit form responses.
- Responses cannot be edited after submission.
- File uploads in assignments are stored securely in private storage. Only admins can access submitted files.
