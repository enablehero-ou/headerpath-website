---
title: Requesting Access
description: How to request an account when an account requires admin approval.
---

Some Qurioos academies are set to **Login only** mode, which means new accounts must be approved by an admin before you can sign in. If you visit an account and don't have an account, you may see a **Request access** option on the login page.

### How to request access

1. Go to the account's login page
2. Click **Request access**
3. Enter your name and email address
4. Submit the form

Your request is sent to the account's admin team for review.

### What happens next

An admin will review your request and either approve or deny it:

- **Approved** — you'll receive an invitation email with a sign-in link. Click the link to create your account and access the account.
- **Denied** — you may receive a notification, or the admin team may contact you directly.

There is no set timeframe for review — it depends on the account's admin team.

### If you don't hear back

If you submitted a request and haven't received a response, contact the organization that runs the account directly. Qurioos does not control approval decisions.

**Need to know**

- Not all academies have the **Request access** option enabled. If you don't see it on the login page, the account is invitation-only — you need to be directly invited by an admin.
- If you already have an account but can't sign in, try requesting a new magic link on the login page.
