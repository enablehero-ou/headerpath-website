---
title: Creating Your First Content Page
description: Build and publish a content page for your team and users in under 10 minutes.
---

Content pages in Qurioos are called **Pages**. Each page contains a series of **Steps** — individual content blocks that users navigate one at a time. Steps can be text, video, quiz, audio, a call to action, or a form.

### Create a page

1. Go to **Admin → Content**
2. Click **New page**
3. Enter a title and click **Create**

The page is created in **Draft** status. Drafts are not visible to users.

### Add steps

Inside the page editor, click **Add step** and choose a step type:

| Step type | Use for |
|-----------|---------|
| **Section** | Chapter headings or intro screens |
| **Text** | Prose content, explanations |
| **Image + Text** | Visual walkthroughs with images |
| **Video** | Embedded or Mux-hosted video |
| **Quiz** | Multiple-choice comprehension check |
| **Recap** | Bullet-point summary with animation |
| **Podcast** | Audio-first content |
| **CTA** | Call to action with a button |
| **Form** | Collect feedback, reflection, or file uploads |

Drag steps to reorder them. Each step can have an optional **label** (e.g., *Essential*, *Think*, *Tip*) and a **callout** (e.g., Alert, Note, Motivation).

### Publish

When your content is ready:

1. Click the **Status** dropdown in the page editor
2. Select **Published**
3. Set the **Visibility** to control who can see it

| Visibility | Who can access |
|------------|---------------|
| **Public** | Anyone, including unauthenticated visitors |
| **Logged in** | Any authenticated user |
| **Groups** | Members of specific groups only |

**Need to know**

- Publishing a page with **Certification** enabled lets users earn a certificate on completion. Configure this under the page's certification settings.
- Set status to **Coming Soon** to show a placeholder to users before the content is ready.
