---
title: Inviting Users
description: Add users and team members to your Qurioos account.
---

You can invite users one at a time or in bulk via CSV. All invited users receive an email with a sign-in link — no password required.

### Invite a single user

1. Go to **Admin → Users**
2. Click **Invite user**
3. Enter their email address and select a role
4. Click **Send invite**

The user appears with **Invited** status until they accept. Once they sign in, they become **Active**.

### Bulk import via CSV

To add many users at once:

1. Go to **Admin → Users**
2. Click **Import CSV**
3. Upload a CSV with columns: `email`, `first_name`, `last_name`, `role`
4. Review the preview and click **Confirm**

All imported users receive invitation emails.

### User roles

| Role | What they can do |
|------|-----------------|
| **User** | Access content pages, earn certificates |
| **Editor** | Edit existing page content |
| **Creator** | Create, edit, and delete content pages |
| **Manager** | Manage creators, editors, and users |
| **Admin** | Full access to all admin features |
| **Superadmin** | Full access + AI content generation |

### Managing existing users

From **Admin → Users** you can change a user's role, deactivate their account, view their progress, or export all users to CSV.

**Need to know**

- If your access mode is **Login only**, only invited users can access the account. Set this under **Settings → Access**.
- Users can also request access if you enable the **Request access** option in Settings.
- Invitations expire. If a user hasn't accepted, resend the invite from their profile.
