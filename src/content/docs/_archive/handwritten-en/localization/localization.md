title: Localization
description: Publish your account in multiple languages to reach a global audience.

Qurioos supports publishing your account in multiple languages. Users see content in their preferred locale, and you can translate every page and step individually.

### Supported locales

Qurioos currently supports four locales:

- **English** (en) — default
- **Spanish** (es)
- **Greek** (el)
- **Hebrew** (he) — includes automatic right-to-left layout

### How to enable additional languages

1. Go to **Settings → Languages**
2. Click **Add language**
3. Select a locale and click **Enable**

The first locale you set is your **primary locale** — the fallback for users who don't have a preferred language set.

### How to translate content

Once a locale is enabled, open any page in the content editor. A locale selector appears at the top. Select a locale and add translated content for each step.

You can also use **auto-translation** (Pro plan) to generate translations automatically. Auto-translated content is saved as a draft translation and requires review before publishing.

### Locale resolution

Qurioos determines which language to show a user in this order:

1. The locale in the URL path
2. A locale cookie set by the user
3. The user's profile preference
4. The language used at signup
5. The browser's Accept-Language header
6. The account's primary locale

**Need to know**

- Translatable elements include: page content, step content, navigation links, homepage sections, and profile field labels.
- Unpublished translations are not visible to users. Publish each translation when it's ready.
