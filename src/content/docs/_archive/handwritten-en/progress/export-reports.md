---
title: Exporting Reports
description: Export user and progress data from your Qurioos account as a CSV.
---

Qurioos lets you export your user data — including progress and role information — as a CSV file for reporting, compliance, or integration with other tools.

### How to export users

1. Go to **Admin → Users**
2. Click **Export CSV**
3. The file downloads immediately

### What the export includes

The CSV export includes a row for each user with:

- Email address
- First name, last name
- Role
- Account status (Invited, Active, Inactive)
- Last login date
- Account creation date

### Progress data

Detailed per-user, per-content page progress is available on individual user detail pages (go to **Admin → Users** and click a user). Per-page progress data shows:

- Completion percentage
- Quiz accuracy
- Status (Not started, In progress, Completed, Certified)
- Certifications earned

**Note:** A bulk progress export across all users and all pages is not currently available via CSV. Contact **support@qurioos.com** if you need this for a specific reporting need.

**Need to know**

- CSV export is available on **Starter** plan and above.
- The export reflects the current state of your user list. It is not a historical snapshot.
- Deactivated (Inactive) users are included in the export.
