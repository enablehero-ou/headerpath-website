---
title: Progress Tracking
description: How Qurioos tracks and displays user progress through your content pages.
---

Qurioos tracks every user's progress through each page automatically. As a user completes steps, their progress is saved and accessible to admins in real time.

### How progress is tracked

Progress is tracked at the **step level**. As a user moves through a page, each step they visit is marked complete. Progress is saved automatically — there's no manual save required.

For anonymous users on full-public academies, progress is stored in browser cookies. Logged-in users have their progress stored to their account.

### Where to view progress

**Per user:** Open any user's detail page from **Admin → Users** to see their progress on every page — completion percentage, quiz accuracy, and current status (Not started, In progress, Completed, Certified).

**Account-wide:** The admin dashboard shows your overall **completion rate** — the percentage of users who have completed at least one content page.

### Progress statuses

| Status | Meaning |
|--------|---------|
| **Not started** | User has not opened the page |
| **In progress** | User has started but not finished |
| **Completed** | User has met the completion threshold |
| **Certified** | User has completed and earned a certificate |

### Clearing progress

Admins can clear a user's progress on a specific page from the user detail page. This resets the user to "Not started" for that page.

**Need to know**

- Progress is per-user, per-page. A user's progress on one page does not affect another.
- Quiz accuracy is tracked separately from step completion and used for certification thresholds.
