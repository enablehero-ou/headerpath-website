---
title: Groups
description: Organize users into groups for targeted content access.
---

Groups let you control which users can access specific pages. When a page's visibility is set to **Groups**, only members of the assigned groups can see it.

### Creating a group

1. Go to **Admin → Groups**
2. Click **New group**
3. Enter a name and click **Create**

### Adding users to a group

From the group detail page, click **Add members** and search for users by name or email.

### Group-restricted content

To restrict a page to specific groups:

1. Open the page in the editor
2. Set **Visibility** to **Groups**
3. Select the groups that should have access

Only members of those groups will see the page in their account.

### Group managers

You can designate a user as a **Group Manager** for a specific group. Group managers can:

- View and manage the members of their assigned group(s)
- Access the admin panel, limited to Users and Groups sections

Group managers are useful for team leads or department heads who need to manage their own team's membership without full admin access.

### Removing users from a group

Remove a user from a group at any time from the group detail page. Removal takes effect immediately and revokes access to any group-restricted content.

**Need to know**

- A user can belong to multiple groups.
- Removing a user from a group does not delete their account or progress — it only removes access to group-restricted content.
