---
title: Navigation
description: Customize the user navigation bar in your Qurioos account.
---

The user navigation bar appears at the top of your account. You can customize its links, structure, and order under **Settings → Navigation**.

### Navigation options

- **Content pages dropdown** — toggle a dropdown menu that lists all visible pages. Disable this if you prefer to manage navigation entirely through custom links.
- **Custom links** — add individual links or grouped links (folders with children)

### How to add a navigation link

1. Go to **Settings → Navigation**
2. Click **Add link**
3. Enter the label, URL, and optionally toggle **Open in new tab**
4. Click **Save**

### How to add a link group (folder)

Link groups let you create a dropdown with multiple child links:

1. Click **Add group**
2. Enter the group label
3. Add child links inside the group

### Reordering

Drag navigation items to reorder them. The order you set here is the order users see.

### Per-locale labels

If your account has multiple languages enabled, each navigation link and group label can have a translation per locale. Click the locale selector on any link to add translations.

**Need to know**

- Navigation changes are visible to users immediately after saving.
- Links added here appear for all users. To restrict content access, use [Group-restricted pages](/articles/admin-guide/groups) instead.
- The navigation bar is responsive — on mobile, it collapses to a hamburger menu.
