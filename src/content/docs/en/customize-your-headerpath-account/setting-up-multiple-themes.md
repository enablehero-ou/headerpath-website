### How multiple themes work?

Multiple themes allow you to create customized versions of your HeaderPath academy portal for different groups of users. Each theme can have its own logo, colors, fonts, and branding to match specific audiences or regional requirements.

### Example: 3 themes

- ‍**Default:** For internal team training.**‍**
- **All customers:** When customers login, they see this theme and course list.**‍**
- **Mexico partners:** When Mexican partners login, they see this theme and course list.

### Add custom colors

Customize your academy's look with brand colors while keeping system colors optimized for accessibility and best learning practices.

### Add custom logo

Upload and configure logos for each theme. A guide to uploading and using your logo across the platform, including supported formats, dimensions, and placement:

- **Supported formats:** PNG, JPG, SVG
- **Recommended dimensions:** 240px × 56px (minimum)
- **Placement:** Header, login page, certificates, and emails

### Assigning themes to user groups

Once you've created the necessary groups of users, then you can connect a theme to a group. When users from that group log in, they'll automatically see the assigned theme.

### Deleting themes

Every account needs at least one default theme which can't be deleted.

### Best practices for multiple themes

- ‍**Maintain consistency:** While each theme should reflect different brand identities, maintain consistent navigation and structure for better user experience.**‍**
- **Limit theme numbers:** Too many themes can become difficult to manage. Consider if user groups can share themes before creating new ones.**‍**
- **Regular updates:** When updating content or making platform changes, remember to check how these changes appear across all your themes.

### Troubleshooting

- ‍**Users seeing the wrong theme:** Verify that the user is assigned to the correct user group and that the group has the intended theme assigned.**‍**
