### Roles and permissions in Qurioos

Qurioos accounts have two types of users: **admins** and **users**. Each type has different levels of access and control over the account.

### Admins

Admins have full control over the account and its content. They can:

- Access the account (whether it’s public or private)
- Manage account settings
- Edit and publish all content (subjects, levels, paths, modules, steps)
- Edit and publish certifications
- View, invite, and delete users and control access levels
- View user reports

### Users

Users have limited access to the account. They can:

- Access only the parts of the account they’ve been given permission to view
- Complete certifications available to them

**Need to know**

- Permissions are set by admins and can be updated at any time.
- A user can be upgraded to an admin (or downgraded) by an existing admin.
